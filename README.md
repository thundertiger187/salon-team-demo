# Team-Kalender – Haardesign Da Giovanni (Demo)

Klickbare **Demo** eines geteilten Team-Kalenders für Haardesign Da Giovanni, Bahnstraße 63, 40699 Erkrath
(Termine pro Mitarbeiter:in, Termin per Sprache, Urlaub & Abwesenheiten, Urlaubsanträge, Teilzeit-/Wechselmodelle).

**Live:** https://thundertiger187.github.io/salon-team-demo/

- Reine Demo ohne Server: Alle Daten liegen nur im Browser (localStorage). Namen, Kund:innen und Termine sind Beispieldaten.
- Die Kunden-App (https://thundertiger187.github.io/salon-demo/) gleicht Terminwünsche, Buchungsmodus, Dauern und freie Zeiten **nur im selben Browser auf demselben Gerät** ab (gemeinsamer localStorage, kein Server) – auf anderen Geräten kommt **nicht** an.
- Neu: „Online-Anfragen“ (Bestätigen / Verschieben), Umschalter Sofortbuchung/Anfrage (Inhaber), Dauer je Haarlänge unter „Leistungen“.
- Zwei Designs: „Klassisch“ (Standard) und „Glas“ (hell, Milchglas-Effekte) – umschaltbar in der Seitenleiste unter „Design“, gespeichert pro Gerät.
- Dieses Repository enthält nur die gebauten, minifizierten Dateien, keinen Quellcode.
